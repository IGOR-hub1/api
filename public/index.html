RabbitHub Catalog API

Catálogo protegido,
acesso temporário.

Os arquivos de dublados, legendados e lançamentos são entregues apenas pela API após uma autorização Firebase e um token de curta duração.

Solicitar token

Entre com uma conta Firebase que foi liberada pelo administrador. O token não é salvo neste navegador.

Endpoints

Envie o token no cabeçalho Authorization. Não use query string para tokens.

  • GET /api/animes?category=dublado
  • GET /api/animes?category=legendado
  • GET /api/animes?category=lancamentos
  • GET /api/animes?category=dublado&slug=one-piece-dublado

Tokens valem 15 horas por padrão. Ao expirar, o cliente solicita outro automaticamente; a troca de API_TOKEN_SECRET invalida todos imediatamente.

Após gerar um token, o exemplo cURL aparecerá aqui.

Como o acesso é controlado

Uma conta é autorizada por e-mail em API_ALLOWED_EMAILS na Vercel ou pela custom claim Firebase animeApiAccess: true. O endpoint de token aceita somente um Firebase ID token válido; a API de catálogo aceita somente o bearer token temporário que ela emite.

O repositório que contém os JSONs deve permanecer privado. Nenhuma camada de API consegue restringir arquivos expostos por um repositório GitHub público.
